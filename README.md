# E-commerce Shop
The **e-commerce system for selling products**, built using a **Microservices architecture** to simulate a real-world e-commerce platform.

The system includes key functionalities such as **Authentication, Product, Inventory, Cart, Order, Payment, Promotion, and Review**. Each service is deployed independently and communicates with other services through **REST APIs, OpenFeign, and Apache Kafka**.

In addition, the project uses **MySQL** for data storage, **Redis** for caching, **Eureka** for Service Discovery, and **API Gateway** for managing client requests.

The goal of the project is to build a system that is **scalable, reduces coupling between services, and simulates backend development processes in a real-world system**.
